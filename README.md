# Tuesday 24 November 2026 — the world in one image

An entry for the [make.fun](https://make.fun) bounty
[news-image-20261124](https://make.fun/bounty/news-image-20261124):
"Sum up 24 November's world news in one image".

`main.py` (Python 3.13, standard library only) draws a 1024×1024
newspaper front page — 36 stories, 7 regions, 13 fields — with a
hand-built vector serif masthead and headlines, 13 code-drawn
illustration scenes, a UTC timeline, a numbers strip, a dotted world
map with numbered pins, a 23-story briefs index, a DATE CHECK box and
a confidence legend. It writes the PNG to `$MAKEFUN_OUTPUT_DIR/entry.png`
and is fully deterministic (identical sha256 on every run).

Run it:

```
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
